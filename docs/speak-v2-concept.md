# Speak v2: Audit and Concept

> Status: **concept for discussion, not a build plan.** Oct 5 2026.
> Part of Flight Presets v2 (`docs/flight-presets-concept-v2.md`). Rules that stay:
> - spoken-first: phones scaffold and vote, nobody types answers;
> - Speak must **not spotlight one student**;
> - the teacher shares one window in Zoom, so there are no second screens and no private teacher views on the shared screen;
> - no usage tracking or "listen for the line" policing;
> - do less, go deeper, with fun breaks between stages;
> - the before → after shows only at landing.

## What Speak is today

Tagline: *"Maximum talk time — fluency over accuracy."*

| Stage | Activity | How the talking happens |
|---|---|---|
| Warm-up | **Character Cards** | Each student gets a character and says one sentence as it, one at a time; then a vote |
| Toolkit | **Language Toolkit** | Key phrases from the topic shown on both screens |
| Break | **Would You Rather / Rank It** | Phones vote, a few students explain |
| Scene | **Scene Igniter** (the "movie") | A cast performs a short scripted scene line by line, then notes and an improv |
| Main event | **Conversation Rounds** | Two students improvise a role-play while the class watches; pairs rotate |
| Break | **Comms Check** (vocab micro) | One "which word fits?" vote |
| Game | Pool (Imposter, Taboo, Connections…) | Game rules |
| Landing | **Final Word** | Every student says one sentence |

**What's strong (keep):**
- The toolkit phrases flow into the scene and the conversation (Lesson Kit), so the language builds.
- Scene Igniter's movie format gives a model before students improvise.
- Conversation Rounds' role cards and complications ("the shop is closing!") make real talk.
- Short, fun breaks between stages.

## Honest problems

1. **Talk time is low for a speaking lesson.** Character Cards, Scene Igniter, Conversation Rounds and Final Word are all one or two students at a time while everyone else listens. In a class of 8, each student speaks for roughly 2–3 minutes of a 60-minute lesson. The tagline promises the opposite.
2. **It's a spotlight format.** Conversation Rounds puts a pair on stage in front of the class, which is exactly what Speak should avoid. Shy students wait, then perform.
3. **Nothing shows progress.** There's no before → after, so the landing has no reveal. Grammar has wings, Debate has the shift, Travel has stamps; Speak ends with one sentence each.
4. **The stages don't add up to one thing.** The character from the warm-up disappears, and the scene, the conversation and the game are separate topics on the same theme. There's no single conversation the class gets better at.
5. **No second try.** Fluency grows by saying the same thing again, better and faster. Every Speak stage is one go, then move on.

## The idea: one conversation, three tries

**The whole lesson builds one real conversation**, taken from the topic (ordering at a café, making plans with a friend, complaining about a phone, asking a teacher for help). Students say it three times, and each time it's better:

1. **Try 1 (takeoff), cold:** what would you say right now?
2. **Try 2 (middle), with help:** with the toolkit phrases and a model to copy.
3. **Try 3 (landing), on your own:** no script, a twist, faster.

The before → after compares Try 1 with Try 3.

### Talk time without a spotlight
In one Zoom room only one person can talk at once, so talk time has to come from **many short turns, fast**, and from **everyone contributing to one shared conversation** instead of pairs performing:
- **Pass the Line:** the whole class builds *one* conversation together. The "mic" passes every line: student A says line 1 (as the customer), student B replies as the waiter, student C continues as the customer… Nobody performs a whole scene alone, and everyone is in it within a minute. The phone shows "your line is next" and two phrase helpers.
- **Quick-fire turns:** 10–20 seconds each, with a fair queue and a visible timer, so a class of 8 all speak in under 3 minutes.
- **Say it again, better (4-3-2):** the same answer three times with shrinking time (40s → 30s → 20s). Saying it again is how fluency grows, and it feels like a game against the clock.

## The flight: fewer stages, each deeper

| Phase | Stage | What happens |
|---|---|---|
| **Takeoff** | **Situation check (before)** | Phones show the real situation and 3–4 possible replies: pick the one you'd use. Then "How confident would you be?" (3 faces). This takes 1 minute and is the **before**. |
| | **Warm-up: quick-fire chain** | One fun question, everyone answers in 10 seconds, the mic passes on. Everyone talks in the first 3 minutes. |
| **Climb** | **Toolkit** (kept) | 5 phrases for the situation, on both screens and in the phrasebook. Each student says one aloud in a sentence. |
| | **The model: Scene Igniter** (kept) | The scripted scene uses the toolkit phrases. This is the model for the conversation. |
| *Break* | Static / Would You Rather | Short, fun, no spotlight. |
| **Cruise** | **Pass the Line** (new, the main event) | The class builds the situation's conversation together, line by line, the mic passing each line. Round 1 follows a frame, round 2 adds a **twist card** (like Travel's Take 2: "they've sold out", "you're in a hurry"), round 3 swaps roles. |
| | **Say it again, better** (new) | Each student answers one personal question from the topic, three times: 40s, 30s, 20s. The phone shows only the timer and their phrase helpers. |
| *Break* | Comms Check or a game | |
| **Landing** | **Situation check (after) + Better answers** | The same situation, new reply options (so it's not memory). Confidence again. The reveal over the arrival scene: "Natural reply: 3 of 8 → 7 of 8 · Confident: 2 → 6". Then **Final Word**: one sentence each, the cold Try 1 now said with the lesson's phrases. |

That's 6 main stages instead of 8, with far more talking per student.

### What happens to the current activities
- **Character Cards:** becomes optional. Either keep it as an alternative warm-up, or drop it from Speak (it stays in the catalogue).
- **Conversation Rounds:** stays in the catalogue and in Captain's Flight (personal questions), but leaves Speak's main slot to Pass the Line, because pairs on stage are a spotlight.
- **Scene Igniter, Toolkit, Final Word, the breaks:** kept.

## What carries through
- **The situation:** takeoff check → toolkit → scene → Pass the Line → Say it again → landing check. One conversation, all lesson.
- **Toolkit phrases:** the phrasebook, phone helpers in every speaking stage, and the landing's reply options.
- **Twist cards:** the same idea as Travel's Take 2, so students meet one consistent challenge across flights.
- **Before → after:** the logbook ("Café · natural replies 3 → 7 of 8") and, in a course, one situation item comes back next lesson as a "still flying?" check.

## New pieces (none decided)
1. **Situation check:** the before/after item (situation + replies + confidence), generated with the topic, with a deterministic fallback.
2. **Pass the Line:** a whole-class line-by-line conversation with a passing mic, twist cards and role swap. It can reuse the performed-dialogue engine's line stepping and the fair queue.
3. **Say it again, better:** a 4-3-2 timer activity with a fair queue and phone helpers.
4. **Quick-fire chain:** a fast warm-up turn queue with a visible timer (could be a mode of the Toolkit or Would You Rather).
5. **Better answers reveal** at landing, plus the logbook deposit.

## Questions for you
1. **The before/after:** "which reply would you use?" + confidence, or can-do statements like Travel's ("Could you order at a café in English?")? Or both?
2. **Pass the Line as the main event:** does a whole-class shared conversation feel right for your classes, or do you want pairs to stay (Conversation Rounds) with shorter turns?
3. **Say it again, better (40s → 30s → 20s):** good fit for kids and teens, or too drill-like?
4. **Character Cards:** keep as the warm-up (and carry the character into Pass the Line), or replace with the quick-fire chain?
5. **Zoom breakout rooms:** do you ever use them? If yes, phones could run real pair work in parallel, which would multiply talk time. If not, the design above works in one room.

## Decisions (owner, Oct 5 2026)
1. **Before/after: both.** The situation check (which reply would you use + confidence) **and** a can-do statement ("Could you … in English?").
2. **Main event: Pass the Line.** Conversation Rounds leaves Speak's main slot.
3. **Say it again, better (40s → 30s → 20s): yes.**
4. **Character Cards: replaced** by the quick-fire chain warm-up.
5. **No Zoom breakout rooms.** Everything works in one room.

## Build order
1. **Situation check** at takeoff and landing (reply choice + confidence + can-do), with the **Better answers** reveal.
2. **Quick-fire chain** warm-up.
3. **Pass the Line** (whole-class conversation, passing mic, twist cards, role swap).
4. **Say it again, better** (4-3-2 timer, fair queue, phone helpers).
5. **Reshape the Speak preset** around the situation + logbook deposit.
