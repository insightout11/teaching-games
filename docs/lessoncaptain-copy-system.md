# LessonCaptain Copy System

This is the teacher-facing terminology guide for LessonCaptain. It keeps the aviation theme as the product's emotional frame while keeping actions and requirements plain.

## Governing rule

Plain language tells the teacher what to do. Aviation language tells them where they are in the experience. Use both together when the aviation term is not self-explanatory.

## Core vocabulary

| Concept | Use | Avoid in teacher-facing copy |
| --- | --- | --- |
| Whole class session | lesson | flight as the only label |
| Lesson sequence | Flight Plan | mission plan |
| Student-facing task | activity | module, item |
| Teaching purpose | stage | slot |
| Short stage | quick check | micro-event |
| Teacher controls | Teacher Cockpit | console without context |
| Learners | students | crew except in celebration/rewards |
| Starting a class | Start live lesson | Launch Mission |
| Moving forward | Next activity | Next Item, Next Module |
| Finishing | Finish Lesson | Complete Flight as the only control label |
| Source material | source, video, reading | grounding as the main instruction |
| Destination progression | World Flight | unexplained handoff language |
| World Flight challenge | Design Mission | mission without context |
| Free usage unit | live lesson credit | Test Flight without explanation |

## Aviation language to keep

Use Flight Plan, boarding, cockpit, route, destination, takeoff, landing, and “You’ve Landed” for framing, transitions, progression, and celebration.

## First-use definitions

- Captain’s Flight: the flagship ready-made lesson sequence.
- Flight Plan: the sequence of activities in a lesson.
- World Flight: an optional class journey mode where destination lessons move the class around the map.
- Design Mission: a World Flight challenge that becomes available after the class collects field notes from different city lessons.
- Test Flight: the free-trial experience. Each Test Flight uses one live lesson credit, whether it contains one activity or a complete Flight Plan.

## Consistency checks

- Use “activity” for the same unit in the planner, live controls, recent sessions, and catalog metadata.
- Use “lesson” for the complete class session.
- Keep the configured Captain’s Flight route as the source of truth for advertised stage labels and counts.
- Pair branded labels with plain meaning at first use, especially for World Flight, Captain’s Briefing, Crew Radio, and Test Flight. Explain that each Test Flight uses one live lesson credit.
