# Course builder review and ready courses (Oct 9 2026)

_For owner review. The Courses page itself is already redesigned (itinerary passes, book upload first)._

## How the builder works today
1. The teacher types a theme, picks a level and 3–8 lessons.
2. AI proposes a connected outline: each lesson gets a title, a topic, keywords and a **goal** (one of 9: Speaking
   Fluency, Discussion & Debate, Vocabulary, Grammar, Collaboration, Creativity, Critical Thinking, Confidence,
   Real-World English). A library video or text is matched to each lesson where one fits.
3. The teacher edits titles, topics and goals, reorders, deletes, saves.
4. Each lesson is launched later from the course page, choosing the class every time.

## What's holding it back
- **The goal decides the lesson type, and 5 of the 9 goals give the same generic lesson** (the "all-around" flight).
  The flights that work best (Speak, Debate, Grammar, and especially **Listening, Travel and Reading**) can't be
  chosen directly; Listening and Travel can't be reached at all, Reading only through the ready book courses.
- **No class.** The course doesn't know who it's for, so it can't use the class's level, Junior mode or age, and the
  teacher picks the class again at every lesson.
- **Only a theme to start from.** You can't hand it your own material per lesson (an article, a video link, a book
  chapter) or pick library items for lessons; the matching is automatic only.
- **No course arc.** Each lesson has its own before → after, but the course as a whole doesn't: no first-lesson
  baseline, no review lesson, no "what we learned this course" at the end.

## Proposed upgrades (build after approval)
1. **Choose the lesson type directly**: Speak, Debate, Listening, Reading, Grammar, Travel, Mix, shown as the same
   chips as the Live Room flights. The AI outline picks a sensible mix; the teacher can change any lesson.
2. **A course belongs to a class** (chosen once, changeable): level, Junior and age come from the class; Board on the
   course page goes straight to the next lesson for that class. No database change needed if we keep using the
   launched-session link, a small one if we want to store the class on the course (I'd ask first).
3. **Bring your own material per lesson**: paste a link or text, or search the library from the lesson row.
4. **A course arc**: lesson 1 sets a baseline (e.g. "say 3 things about food"), the last lesson repeats it so the
   class sees how far it came, plus an optional review lesson using the words saved from every lesson. Shown on the
   course pass and in the class logbook.
5. **Start from a book or a ready course in the same builder** (today these are separate paths).
