## Required Views Per Plane

Each aircraft needs three transparent-background assets:

- Side view: Hangar, map-adjacent UI, runway taxi, arrival scenes.
- Head-on front view: runway/takeoff scenes.
- Three-quarter front view: cinematic overlays and turbulence.

## Style Lock

Use the LC Wayfarer as the baseline rendering quality, but do not make every
plane a repaint of the same aircraft. Each choice in a range tier should have a
recognizable silhouette:

- Blue as the primary brand color with white accents and light cyan highlights.
- Plane generation must not create letters, logos, symbols, badges, or tail text.
- Apply the real LessonCaptain mark after generation from
  `src/components/world-flight/arrival-scene/lc-brand.ts` (`LC_L_MARK`) or the
  matching files in `public/lessoncaptain-mark-*.svg`.
- Only place the mark where it reads cleanly. If an angled/front view does not
  have a clear tail surface, leave it unmarked instead of using a fake or warped
  logo.
- Blank tails are acceptable as a temporary production state. A misplaced,
  distorted, generated, or partial logo is not acceptable.
- Distinct forms within the same range tier: trainer, regional turboprop,
  floatplane, bush plane, cargo aircraft, racer, etc.
- Clean dark navy outlines.
- Polished educational-game rendering.
- Not toy-like, not military, not yellow/orange cartoon.
- Transparent background after chroma-key removal.
- No text except the single `L`, no badge lettering, no watermark.

## Prompt Template

Use a flat `#00ff00` chroma-key background, then remove it with:

```powershell
python C:\Users\insig\.codex\skills\.system\imagegen\scripts\remove_chroma_key.py `
  --input <source.png> `
  --out <transparent.png> `
  --auto-key border `
  --soft-matte `
  --transparent-threshold 12 `
  --opaque-threshold 220 `
  --despill
```

Keep generated chroma-key sources in `tmp/world-flight-plane-assets/` while reviewing.
Only accepted transparent assets should be copied into `public/assets/flight/planes/`.

Accepted PNGs can be converted to WebP with Pillow:

```powershell
python - <<'PY'
from PIL import Image
from pathlib import Path
for png in Path('public/assets/flight/planes').glob('lc-*.png'):
    Image.open(png).convert('RGBA').save(png.with_suffix('.webp'), 'WEBP', quality=90, method=6)
PY
```
