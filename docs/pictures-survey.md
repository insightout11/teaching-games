# Picture opportunities — 20 October 2026

Report only. Based on the game/activity registries, `retired-plugins.ts`, each screen's render branches and the student panels. Current catalogue: 13 active games and 64 active activities, including the two reading-flight entries. This is a screen opportunity survey, not a claim about teaching results.

This brief implements Flash Quiz, Vocab Sprint, Vocab Micro, Language Toolkit, Taboo Sprint, Hot Seat and Scene Igniter jobs. Vocab Radar is retired from browse lists but is explicitly covered for existing lessons. Those implementations are not additional recommendations below.

## Highest value first

Use pictures as optional context. Keep complete text and spoken instructions. Each shown photo needs a visible credit, failure handling and a cached free lookup. Never search from a correct option, private goal, student's personal detail or an unrevealed consequence. A query's apparent neutrality cannot establish that the returned picture or its title will be spoiler-free: use reveal-only pictures for assessed knowledge unless a teacher has reviewed the actual image.

## Other surfaces checked

The widget registry was reviewed alongside the catalogue. Word Bank word-and-meaning cards are the strongest follow-up: concrete meanings only, using the same metadata/cache rather than guessing from a word. Class Board public topic/evidence cards and teacher-authored Poll choices could benefit next, with author review and equal treatment of choices. Class Questions and Word Cloud need teacher curation before any image search on student text. Exit Ticket could reuse a previously released public topic image. Picture Reveal already has its own image mechanic. Timer, Random Picker, Spinner and Teams do not benefit from stock photos: keep controls/names legible; student avatars are a separate feature.

Arrival cards, topic/facts boards and the protected room/flight views were considered only for survey context. They are outside this branch's code changes. Arrival destination photos should use already known public destination data; the facts board already offers free-picture suggestions and credits. No changes to `src/components/live-room/`, `src/components/session/live-room/`, `src/lib/live-room/` or `src/data/world/` are proposed here.

Retired/vaulted plugins are not new implementation targets. Apart from explicitly requested Vocab Radar, they need no photo work unless the owner restores them to the catalogue. Generated/cached legacy content without a deliberate picture phrase remains text-only; no new AI call should be made simply to backfill an image.
