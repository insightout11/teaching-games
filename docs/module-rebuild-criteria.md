# Module Rebuild Criteria (Lightweight Audit)

Status: **LOCKED** — design filter, not bureaucracy.

Rule:
- If a module fails **2+** questions → redesign.
- If a module fails **Measurable Output** + **UI Simplicity** → **rebuild**.

## The 5 questions

### 1) Simultaneous energy
Does it create simultaneous energy?
- If students are waiting/idle, redesign.

### 2) Measurable output
Does it produce measurable output?
- If it’s fun but untrackable, redesign.

### 3) Goal adaptability
Can it adapt to different teacher goals?
Examples: fluency vs accuracy vs exam review.
- If not, adjust inputs/weighting.

### 4) PPP stage clarity
Does it clearly serve a PPP stage?
- Presentation / Practice / Production
- If unclear, clarify internally.

### 5) UI simplicity
Does it feel simple in the UI?
- If teacher friction is high, simplify.

## Process
1) Pick one module.
2) Run it through the 5 questions.
3) Identify weaknesses.
4) Redesign deliberately.
5) Move to the next.

One-by-one. Not a big-bang refactor.
