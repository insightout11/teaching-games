# Teaching Games

AI Speaking Games for Online ESL Teachers.

## Product Definition

**V1 = Game Library + Lesson Playlist (teacher-run)**

- Not a platform. Not an LMS. Not a student app.
- Open link → pick game → play
- Works with screen share (no student accounts)

## MVP Game Set

1. **VocabSprint** - Vocabulary recall race
2. **GrammarBoss** - Grammar error identification
3. **Debate Dash** - Quick debate prompts
4. **Roleplay Roulette** - Scenario-based roleplay
5. **Speed Interview** - Job interview practice

## Tech Stack

- Frontend: React
- Backend: Supabase (auth + DB)
- AI: Google Gemini API

## V1 Pricing

- **Free:** Access to 1 game (VocabSprint basic)
- **Pro ($10–15/mo or $49/season):**
  - All games
  - Lesson Playlist Builder
  - Save/export playlists
  - Generate variations
